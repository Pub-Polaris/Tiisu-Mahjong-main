## 九、规则红线（含 2026-10-18 新增，务必逐条遵守）

原有：
- 七对形的役满/特殊役必须前置判定（小于七/大于七 在 seven_pairs 之前硬编码）。
- 四暗刻（28）会截走 清老头/绿一色/字一色/三国将，需 notIf 前置互斥。
- 暗刻系判据已统一，勿按旧实现拆开。
- 小于七/大于七：三元（5z/6z/7z）各一对 + 一对风，dragons 恰好 3。
- 7 赋起和；不足显示 no_yaku 属预期。
- 牌 id：引擎「花色在前」（m1/z5）；图片文件名「数字在前」（1m.svg）；**文档里写牌一律数字在前（123m、22z）**。

新增（2026-10-18，之前交接缺失）：
- **高目优先**：同一手牌有多种拆法时取赋数最高者；赋数并列比役种数，仍并列取先出现的。
  `WinChecker.maxSplit = true` 为默认。
- **可选役默认关闭**：7 个役带 optional（全数、全数筋和、同色老少、同色双老少、双色双老少、双双逢、三双逢）。
  验证台会全部启用，**普通对局不会** —— 写测试时注意，别在普通 checker 上断言它们。
- **起和门槛先于听牌型奖赏**：先判 totalFu < baseFu 直接返回 no_yaku，再叠加嵌张/边张/单钓/双碰/筋和。
- **杠 = 14 + 杠数**：暗手长度 = need*3 + 2，need = 4 - meldCount；1 杠全手 15 张、3 杠 17 张。
- **双双逢 / 三双逢**：2 / 3 种不同花色、双数、相邻差 2 的刻子（如 222m + 444p + 666s）。
- **三七之花**：777m 777p 777s（三组必须**全暗**）+ 第 4 刻子 + 雀头，余 5 张须为三元/四风/1·5·9；
  自摸=双役满 70000、荣和=单役满 35000，不计赐马。
- **同色双老少 结构不可达**：同色两组 123 + 两组 789 + 雀头 → 每张牌出现偶数次 → 整手必判为七对子，
  七对形不构建 groups → 判据恒 false。不是 bug。
