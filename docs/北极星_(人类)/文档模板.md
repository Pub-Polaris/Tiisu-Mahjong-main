## 一、适用范围

适用于 `docs/` 下所有 Markdown 文档，以及规则书 HTML 的新增区块。

**例外**：仓库根目录的 `AGENTS.md` 遵循 [agents.md](https://agents.md) 官方骨架（英文 Summary + Overview / Build & Test / Style / Testing / Security 等章节），并使用「摘要/面向/基线 + 页脚」的字样；它不要求「目录」与「状态一览」，但仍须有页脚版本戳。`CLAUDE.md` 仅作兼容入口，不受本模板约束。

---

## 二、文档骨架

每份文档按此顺序（短文档可省略目录）：

```
# 标题

> **摘要**：一句话说明这份文档解决什么问题。
> **面向**：给谁看（北极星 / opencode / DSH / 美术 / 通用）。
> **基线**：代码位置 + 文档版本 + 对应备份名。

## 目录                          ← 超过 5 节的文档必须有

1. [章节名](#锚点)
2. ...

## 状态一览                      ← 涉及实现状态的文档必须有

| 项 | 状态 | 备注 |
|---|---|---|

---

## 一、章节名
## 二、章节名
...
（章节内可用 ### 子级）

---

> 页脚：文档版本 `YYMMDD`（YYYY-MM-DD） · 对应备份 `backup_*.tar.gz`
```

## 三、标题与编号规范

- 标题层级：`#` 文档标题（唯一）；`##` 一级章节；`###` 子节。
- 章节编号用**中文数字**（一、二、三…）；子节用**阿拉伯数字**（1.1、1.2）或 `###` 无编号。
- 编号连续、不跳号；若确需保留历史编号（如规则书正文），在该文档的"状态一览"中注明。
- 锚点：中文标题的锚点由 GitHub 规则生成（去标点、空格转 `-`、保留中文）。规则书 HTML 用 `id="secN"`。

---

## 四、状态标记规范

**统一使用文字**（不使用 emoji），取值限定为：

| 标记 | 含义 |
|---|---|
| 已实现 | 功能完整可用 |
| 部分 | 已实现但有已知差异（须在备注说明差异） |
| 未实现 | 尚未实现 |
| 已修复 | 曾经的缺陷已修好（用于缺陷追踪类文档） |
| 有意不补 | 经决策维持现状（不算缺陷） |

表格中用"状态"列；行内可用「部分 · 说明」形式。

> 例外：`CHANGELOG.md` 的"待办"区可用「未实现 / 有意保持现状」，语义同上。

## 五、语言与术语

- **语言**：全中文；代码标识符、设置键、文件名、函数名保留原文。
- **术语**：赋（不是番）、点（点数）、岭上(马)、赐马、跳墩、王堆、门风、场风、役牌、门清、副露、食降、可选役。
- **牌记号**：`123m456p789s1122z`（m=万 p=饼 s=索 z=字，字牌 1z东…7z中）。
- **路径**：统一 `P:\Playground\...`。
- **不写"我猜/也许"**：不确定的写「待核对」并列出核对方法。

## 六、变更页脚

每份文档结尾必须有：

```
> 页脚：文档版本 `YYMMDD`（YYYY-MM-DD） · 对应备份 `backup_*.tar.gz`
```

- 版本号规则 `YYMMDD`（`260926` = 2026-09-26）。
- 修改文档时：更新页脚版本/日期/备份名，并在 `docs/OpencodeAgent_老Agent想说的话/CHANGELOG.md` 追加一条。

## 七、目录分区与命名

| 分区 | 面向 | 放什么 |
|---|---|---|
| 仓库根目录 | 所有 agent | `AGENTS.md`（主契约）、`CLAUDE.md`（兼容入口）、`scripts/`（冒烟与探针） |
| `docs/北极星_(人类)/` | 项目与作者本人 | 规则书、代码地图、个人指南、规则缺口、设计、模板、自检、给北极星的信、导航 |
| `docs/DSH/` | Deepseek Harness | 项目交接、已知坑、历史归档 |
| `docs/OpencodeAgent_老Agent想说的话/` | opencode agent | 工具调用说明、CHANGELOG |
| `docs/README.md` | 通用入口 | 总索引 + 先读路径 |

命名约定：
- 规则书保留原文件名（含版本戳），不做重命名。
- 设计文档前缀 `design_`。
- 带日期的快照文档后缀 `_YYMMDD`（如 `文档自检_260926.md`）。
- 不使用空格；中文可，但需保证引用它的链接同步更新。
