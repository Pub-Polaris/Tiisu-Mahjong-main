## 六、怎么用这份清单

- 补某条规则：先到规则书原文确认赋数与条件，再改 `ike.json` + `src/winchecker.js`（役种）或 `src/engine.js`（流局/连庄/点数）。
- 每补完一条：把对应行状态改为「已实现」，并补一句"在哪实现的"；同时在 `docs/OpencodeAgent_老Agent想说的话/CHANGELOG.md` 追加一条。
- 改完必须跑 `python scripts/run_all.py`（或 `cmd /c scripts\run_all.cmd`）确认全绿。
- 状态用词统一：已实现 / 部分 / 未实现 / 有意不补。
