## 一、先确认三件事

1. 这个系统是可以被理解的 —— 是。它已经被拆成职责单一的小文件。
2. 这套操作的边界是可预测的 —— 是。每个文件只做一件事，接口稳定。

**一条主线：** 麻将游戏 = **牌（tiles）→ 判役（winchecker）→ 对局（engine）→ 界面（index）→ 记录（notation/tenpai/uuid）**。AI 是外挂的决策器。

```
└── backup\             版本备份（tar.gz）
```

**为什么这样分：** 越不依赖别的东西的，越往根靠；越独立的逻辑越往 `src\` 塞；给人看的、给历史看的，各自归位。这样改动任何一层，都不会误伤别处。

**路径引用要点：**
- `index.html`（根）用 `<script src="src/*.js">` 加载逻辑。
- `tiles.js` 的 `tileSvg()` 返回 `mj_tiles/...`（相对**页面** index.html 解析，页面在根，无需 `../`）。
- `portal.html` / `debug.html` 通过 `/api/*` 与 server 通信；文档链接指向 `docs/北极星_(人类)/*`。
- `server.py` 静态服务根目录，`/` 重定向到 `/portal.html`。

## 三、纯函数层（没有 DOM、没有状态，谁都能用）

### `tiles.js` — 牌本身
- `createDeck()`：136 张标准牌（万/饼/索 1–9×4 + 字牌 东南西北白发中×4）。
- `shuffle(arr)`：Fisher-Yates 洗牌。
- `sortHand(hand)`：排序 万<饼<索<字，字牌按东南西北白发中。
- `countTiles(hand)`：按 id 统计张数。
- `parseTileString("123m456p789s1122z")`：**手牌字符串 ↔ 牌对象数组**，调试的命门。
- `tileDisplay(t)` / `tileSvg(t)`：显示文本 / SVG 路径。
- **意义：** 所有文件都依赖它，但它不依赖任何人。

**怎么改**：用 `parseTileString("11122233344455z")` 直接构造测试手牌；换牌面样式改 `tileSvg` 路径或 `tileDisplay` 文本；**不要在这里加游戏状态逻辑**。

### `notation.js` — 牌的「人类语言」
- `handToStr(hand)` → `"123m456p789s1122z"`；`meldsToStr(melds)` → `"吃:234m 杠:8888m"`。
- `discardsToStr(discards)` / `seatLabel(p)` / `playerNotation(p)`。
- **意义：** 让牌变成能读、能存、能回看的文本。

**怎么改**：改日志牌面显示格式改 `handToStr`；加字段改 `playerNotation`。只影响日志/文本，不影响判定。

### `tenpai.js` — 听牌判定
- `listTenpai(checker, hand, melds, opts)`：34 种牌逐一试听，返回 `{tile, success, totalFu, noYakuGap}`。
- `noYakuGap` = 起和门槛 − 实际赋（差几赋才够和）。
- **意义：** 流局时能知道「谁差一口气、差在哪」。

**注意**：每张牌跑一次 `checkWin`（最多 34 次），性能敏感，别在每帧调用。

### `uuid.js` — 身份的锚
- `getPlayerUUID()`：Cookie 持久化 `XXXX-XXXX-XXXX-XXXX`（一年）。
- `generateAIUUID(pu, idx)`：AI = 玩家前三段 + `1111/2222/3333`。
- `maskUUID()`：`A-****-****-D`。

**怎么改**：换派生规则改 `generateAIUUID`；改有效期改 `max-age`。**改了会改变身份，已存日志夹名会变。**

## 四、判役层

### `winchecker.js` — 和牌判定的唯一裁决者
- **结构拆分（纯函数）**：`isSevenPairs` / `isSevenHonors`（大七星）/ `splitStandard` / `findPair` / `splitGroups`。
- **`WinChecker` 类**：
  - `checkWin(hand, selfDraw, hasCalled, ankanCount, minkanCount, melds, kans, firstTurn, discards, winTile, winCtx)` —— **全系统最核心的函数**。
    - `winCtx` 可选：`{seaMoon, haiDei, riverFish, lastTileVisible, seatWind, roundWind, daxingqi}`。
  - `conditionFn(id)`：所有役种的判定函数表。
  - `getYakuFu(id)` / `getHonorYaku` / `isHalfFlush` / `isFullyFlush` / `isFiveGates` / `hasKachi7`。
- **关键设计：** `hand` 只收**暗手**，`melds` 是**固定面子**（副露不再被重排）——P08 修出来的。

**怎么改**
- 改役：在 `conditionFn(id)` 找对应 id 改逻辑。
- 新增役：① `ike.json` 的 `yaku[]`/`highYaku[]` 加条目；② `conditionFn` 加同名判定；③ 可副露降级加 `"kaishoku":true`，门清限定加 `"menzen":true`，可选役加 `"optional":true`。
- 删役：从 `ike.json` 删条目即可（`conditionFn` 留着无害）。
- **警告**：`conditionFn` 签名 `(hand, groups)`——`hand` 是**全手（暗手+副露）**，`groups` 是**合并后的面子数组**。

### `aiPlayer.js` — 决策器（外挂）
- `getAIDiscardIndex(hand, game)`：返回该弃哪张的**索引**。策略：速和优先（保对子/搭子、弃孤张字牌）。

**怎么改**：调权重数值（对子 +28、邻牌 +20、孤张字牌 −14 等）；换 AI 就重写这个全局函数（index.html 已 `<script>` 加载）。

## 五、对局层

### `engine.js` — 整局游戏的灵魂（最大文件）
- **`TiisuPlayer`**：一个玩家（手牌/弃牌/副露/杠/UUID/是否庄/门风）。
  - `totalTiles()` / `kongCount()` / `addMeld()` / `findPonMeld()` / `reset()`。
- **`TiisuMahjong`**：整局状态机。
  - **装配**：`init(config, checker, playerUUID, settings)` / `applySettings(settings)`。
  - **场次**：`updateSeatWinds()`（门风轮转）/ `advanceDealer()` / `rollDice()` / `determineDealer()` / `roundLabel()` / `advanceRound()`（终局判定 + 段位点）/ `setMode()`（初始点数 / 终局场风）/ `settleRankPoints()`（段位点）。
  - **牌山**：`setupWallAndCut(dice)`（模型 C：活牌山→王堆→岭上；王堆耗尽才荒牌）/ `deal()` / `draw()`。
  - **回合**：`discard()`（记录首巡听牌 / 拔厄计数）/ `nextTurn()` / `aiTurn()` / `humanDiscard()` / `humanDraw()`。
  - **副露**：`meldOptions()` / `canChi()` / `chiOptions()`（吃多选）/ `checkMelds()` / `aiMeldDecision()` / `applyMeld()`（明杠补岭上）/ `doKan()`（含抢杠）/ `checkRobKan()` / `isKokushiShape()` / `canAnkan()` / `canKakan()` / `tileFromId()`。
  - **和牌**：`tryRon()` / `checkRon()` / `declareWin()`（连庄奖励 / 出岭）/ `declareDaxingqi()`（大七星直接获胜）/ `declareMultiRon()`（三家和流局 / 双和子跳庄）/ `splitPayment()` / `buildWinOverlay()` / `buildMultiWinOverlay()`。
  - **偶发役**：`buildWinCtx()`（海上月/河中鱼/海底月/和绝张/岭上炮/岭上花/杠立/人和/**水滴石破** + 圈风/门风）。
  - **流局**：`flow()`（听牌流局本场+1 / 未听返杠 / 无役听牌罚则 / 七日终战）/ `checkSpecialFlow()`（四风连打 / 拔厄）/ `declareSpecialFlow()` / `buildFlowOverlay()` / `isTenpai()` / `isNineOrphans()` / **`isThirteenUnrelated()`**（十三不靠）/ **`flowOptions()`**（推牌条件汇总）/ **`humanFlow()`**（统一流局按钮入口）/ **`declarePushFlow()`**（九种九牌 / 十三不靠共用）。
  - **罚则**：`applyNotenKanPenalty()` / `applyNoYakuTenpaiPenalty()`。
  - **记分**：`calcPoints()` / `calcFinalPoints()`（含 pointsBonus）/ `honbaBonus()`（连庄奖励 700/根）/ `checkDeungnyeong()`（出岭）。
  - **记录 / 存档**：`recordStep()` / `flushRoundLog()` / `clearRoundLogs()` / `saveSessionState()` / `applySavedState()` / `reportStats()` / `reportRound()`。
  - **运行时**：`executeCommand(cmd)` / `resetAll()` / `stopAuto()` / `scheduleNextRound()`。
  - **UI 触达**：`showAction()` / `hideActionBar()` —— 只存状态（`_actOpts/_actMsg/_actLeft`），由 `index.html` 的 `renderActionArea()` 绘制。

**怎么改**
- 节奏：`aiTurn()` 里的 `this.speed`。
- 配牌/定庄：`setupWallAndCut()` / `determineDealer()`。
- 记分：`calcPoints()` / `declareWin()`（分摊、庄家 ×1.5）。
- 副露：`applyMeld()` / `chiOptions()`。
- 门风/场风：`updateSeatWinds()` / `advanceDealer()`。
- 偶发役：`buildWinCtx()`。
- 赐马：`maNextId()` / `resolveMa()`。
- **警告**：这是状态机。注意回合流转（`turnIndex`）、副露后的 `_skipDraw`、杠的 `kongCount` 补位、以及 `advanceRound()` 的终局防重。改完开「全自动」打几局确认不卡局。

### `handAnalyzer.js` — 手牌直觉提示
- `analyzeHand(hand)`：返回 `{description, ...}`，界面「手牌分析」用。纯展示，不影响判定。

## 七、服务端

### `server.py` — 静态 + API + 日志 + 归档
- 静态文件服务（127.0.0.1:7777，`/` → `/portal.html`）。
- API：
  - `GET/POST /api/settings` → `settings.json`（合并默认值、深拷贝）。
  - `GET/POST /api/state` → `state.json`（会话存档 + `game_cmd`）。
  - `GET/POST /api/stats` → `stats.json`（累加 / `{kind:'reset'}`）。
  - `POST /api/log` → `logs/output.txt`。
  - `POST /api/roundlog` → `logs/<会话>/局NNN_玩家_UUID/log.txt`。
  - `POST /api/round_end` → 归档某会话目录为 tar.gz。
  - `POST /api/chrlog` → 浏览器 console 日志。
- **启动时**：把上一会话目录归档为 `logs/archive_<会话>_<时间戳>.tar.gz`。

**怎么改**：启动 `python server.py --verbose`（或双击 `run.cmd`）；改端口改 `PORT`；加接口在 `do_POST` 加分支；**改完必须重启 server**。

```

和牌: declareWin/declareMultiRon → 赐马 resolveMa → calcPoints → splitPayment → 明牌 → 写日志

新会话: server 启动 → 归档上一会话 tar.gz
```
