## 1. 牌山显示 → 调试选项

- 现状：`index.html` 中 `.wall-viewer`（牌山 / 王牌堆查看器）常显在桌面下方。
- 改法：
  - 新增设置项 `showWallViewer`（默认 **关闭**），存入 `settings.json`。
  - 默认隐藏 `.wall-viewer` → **下方区域完全空出**。
  - `debug.html` / `portal.html` 增加「显示牌山」勾选（持久化）。
  - 牌山数据仍在引擎中（`game.wall` / `game.rinshan`），只是不画。
- 相关文件：`index.html`（隐藏 + 条件渲染）、`server.py`（DEFAULT_SETTINGS 增项）、`debug.html`、`portal.html`。

## 2. 操作按钮 → 主视角手牌上方一行，其上是长考倒计时

- 现状：`#actionBar` 是页面底部的弹出条（`showAction()` 控制）；`#seatControls` 是手牌上方的和牌!/杠/流局。
- 改法：把**两类按钮合并成一行**，渲染到「主视角（下座人类）手牌上方」：
  ```
  [ 长考倒计时  ⏱ Ns · 提示语 ]        ← 其上是倒计时
  [ 荣和 ][ 吃(可多个) ][ 碰 ][ 杠 ][ 过 ]   ← 行动窗口
  [ 和牌! ][ 杠 ][ 流局 ] [点击手牌出牌]      ← 自己的出牌阶段
  ```
  - 引擎 `showAction()` 改为只存状态（`_actOpts / _actMsg / _actLeft / _actOnExpire`）+ 每秒回调 `renderActionArea()`。
  - `index.html` 新增 `renderActionArea()`，读引擎状态画一行按钮 + 上方倒计时。
  - 移除底部 `#actionBar` 的 DOM 依赖（保留引擎计时逻辑）。
- 相关文件：`src/engine.js`（showAction/hideActionBar 重构）、`index.html`（seat 内 `#seatActions` + renderActionArea）。

## 3. 手牌 14 张/行换行；赋马放左上角；下方区域空出

- 手牌换行：`.ptiles.wrap` 改为 `grid-template-columns: repeat(14, min-content)`，一手 14 张即一行（下座 50px 牌 ×14 ≈ 742px < 1100；上座隐藏/明牌用 32px 小牌也放得下）。

- 下方区域：`.wall-viewer` 默认隐藏（见第 1 项），底部只留 runtime-bar 与 debug-log。
- 相关文件：`index.html`。

## 4. 赋马（赐马）机制 —— 待确认

### 规则表原文（已查）

> 「翻开剩余岭上作为奖赏指示牌（赐马），**1 张对应 1 赋，多张不叠加；不算入起和役**」

### 我的理解（待你确认）

1. **马牌来源**：和牌结算时，把**剩余未摸走的岭上牌**翻开作为「赐马指示牌」。
2. **指示规则（类立直宝牌）**：每张马牌指向「下一张」：
   - 数牌：1→2→…→9→1（同花色进位）
   - 风牌：东→南→西→北→东
   - 三元：白→发→中→白
3. **计赋**：胜者手牌（含副露）若含有马牌指向的那张牌：
   - 「一张马牌不对应手里多张牌」→ 每张马牌最多计 **1 赋**（手里有 2 张同牌也按 1 计）；
   - 「多张马牌时，手牌对应数 < 马牌数 → 按手牌对应数奖励；相等 → 全部奖励」→ 指向同一张牌的马牌数为 g、手里该牌张数为 c 时，该组计 `min(g, c)` 赋。
4. **不算入起和**：赐马赋不参与「7 赋起和」判定，仅在已成和后加入点数计算。
5. **高役除外**：规则表「六、高得点役种与役满【注意】以下役种不计赐马」→ 倍满/役满和牌不计赐马。

### 待确认问题（已确认）
- [x] Q1 计赋规则 = 每组 `min(g, c)`（例：2 张马都指向 5m、手里 5m×2 → 2 赋；手里 5m×1 → 1 赋；1 张马指向 5m、手里 5m×4 → 1 赋）
- [x] Q2 「不算入起和」= 先按 7 赋门槛判定可否和，再叠加赐马赋计点
- [x] Q3 倍满/役满（handType=highyaku）不计赐马（大七星直接获胜路径不涉及）
- [x] Q4 指示牌顺序 = 立直宝牌顺序（1→9→1、东南西北、白发中）
- [x] Q5 只算剩余岭上（被杠摸走的马牌不算）
- [x] Q6 役种表加「赐马 +N赋」行（灰色注释，不参与起和）
