### 实现要点
- `winchecker.js` 新增判定：`isFourKings` / `isFourAnkou` / `isAllGreen` / `isAllHonors` / `isAllTerminals` / `isNineGates` / `isThreeSevenFlower` / `isBeautySevenPairs` / `isFourKanDaikan` / `isNorthSouthSelf`；模块级新增 `isKokushi13`。

- **大七星**：`isSevenHonors` 改回严格版（**只能 11223344556677z**，每种字牌恰 2 张）；并**去掉旧的 14 赋计分**，改为只标记（由 engine 结束本局 + 记统计）。
