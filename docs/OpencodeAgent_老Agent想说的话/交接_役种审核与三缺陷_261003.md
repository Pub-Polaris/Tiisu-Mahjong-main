### 2. 暗刻系统一 + 删除重复键 — `9cb9435`

北极星原话：**「暗刻系也算手上的暗刻（双碰例子发现）」**

**缺陷**：`两暗刻` / `三暗刻` 的判据在 `conditionFn` 里**各写一份**，而且——

```js
// 同一个对象字面量里，three_ankou 定义了两次！
three_ankou:()=>{...一份...}      // 位置 A
...
three_ankou:()=>{...另一份...}    // 位置 B ← 静默覆盖 A，改 A 根本不生效
```

**修法**：统一为 `_concealedAnkouCount()` = 暗手 3 张同牌组数 + 暗杠数；`两暗刻`/`三暗刻` 都调它；**删除重复键**。

```js
_concealedAnkouCount() {
    const m = countTiles(this._concealedHand || []);
    let n = 0;
    for (const c of m.values()) if (c >= 3) n++;
    n += (this._ankanCount || 0);
    return n;
}
two_ankou:()=>this._concealedAnkouCount()>=2,
three_ankou:()=>this._concealedAnkouCount()>=3,
```

> **口诀**：双碰和牌时，被和牌张补全的那一组**同样是手上可见的暗刻，必须计入**。
> **给你留的坑**：同一对象字面量里**别重复定义同一个键**（静默覆盖，症状是"改了没反应"）。

### 3. `小于七 / 大于七` 硬编码 — `dfec32f`

**北极星口径**：
> `112233m/p/s` 的意思是一个花色的三张连续牌（`m/p/s` = **任选一个花色**，不是三个都用）
> 是四对（字牌）

| 役 | 数牌 | 字牌 | 张数 |
|---|---|---|---|
| 小于七 | `112233`/`223344`/`334455`/`445566`（**一个**花色） | 四对 | 6 + 8 = **14** |
| 大于七 | `778899`（一个花色） | 四对 | 6 + 8 = **14** |

**缺陷（结构性，最关键）**：

```js
// winchecker.js ~line 153
if (meldCount === 0 && isSevenPairs(fullHand)) { handType='seven_pairs'; ... }
else { ...拆面子... }
```

这两个形状**天然就是七对形**。一旦落进 `seven_pairs` 分支，**高役循环整段不执行** →
**光加谓词永远无效**，实测原先输出 `混一色:5+缺门:3+七对子:7`（fu=15/16）。

**修法**：在**七对分支之前**加硬编码前置判定，命中即直接 `return handType:'highyaku'`：

```js
for (const _hid of ['less_than_seven', 'greater_than_seven']) {
    // 命中 → 组 activeYaku，并按役书「附加混一色得点」叠 混一色，直接 return
}
```

配套新增模块级 `_xyShape(hand, loNums)` / `isLessThanSeven` / `isGreaterThanSeven`：
字牌恰好 8 张 = 4 对（三元占 1–3 对，其余风牌）；数牌恰好 6 张、同一花色、恰为指定三连对各 2 张。

**实测**：

```
大于七 m778899 + 四对 → 大于七:14 + 混一色:5 = fu 19
小于七 m112233 + 四对 → 小于七:14 + 混一色:5 = fu 19
（223344 / 334455 / 445566 同样 fu 19）
```

> **给你留的坑（很重要）**：**七对形的手进不了高役循环**。
> 以后再遇到"形状本质是七对子"的役满/高役，**必须在七对分支前做前置判定**，只加谓词无效。

## 五、环境坑（我踩过的，供你避雷）

1. **控制台是 GBK**：`print` 中文会 `UnicodeEncodeError`。所有报告**写 UTF-8 文件再用 read 工具看**，别直接 print。
2. **行尾**：仓库 blob 是 LF、`core.autocrlf=true`。任何编辑脚本都要**按二进制写**（`io.open(..., newline='')` 或 `'wb'`），否则会把整个文件变 CRLF。
3. **无头 Edge 取 DOM**：`--headless=new --dump-dom URL > file`，然后解析。注意 **`--virtual-time-budget` 设大**；页面引用几百张图时会很慢（我用"去掉 `<img>` 的精简页"绕开）。
4. **别用 PowerShell 内联 Python**：引号/正则会被反复破坏。**一律写成 .py 文件再执行**。
5. **`spec_ids` 类小工具先自测**：我曾把 `m123` 解析成 `['3m','31','32']`，导致**所有校验结果都是垃圾**、白折腾很多轮。**写解析函数先打印一个样例确认**。
6. **git 敏感操作**：`git -C P:\Playground` 在受限沙箱下会被拒；需 `danger-full-access`。当前会话策略已是 full-access。
