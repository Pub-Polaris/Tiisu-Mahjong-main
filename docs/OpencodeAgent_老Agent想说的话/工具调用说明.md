## 二、启动服务器

```powershell
python server.py
```

- 服务地址：`http://127.0.0.1:7777/`。
- 根路径 `/` **302 重定向到 `/portal.html`**；`index.html` 不重定向，无参数时自动开始默认东风场（4 局）。
- 所有页面都必须通过该服务器访问（`index.html` 需 `fetch('ike.json')`，直接双击文件会失败）。
- **确保只有一个 server 进程**：两个 python 争 7777 会间歇性导致 `WinChecker is not defined`。排查：`Get-CimInstance Win32_Process -Filter "Name='python.exe'"`。
- **无头测试**：初始化已改为等 `window.load` + 依赖就绪等待；普通模式（`?mode=4`）应见 `class="tile clickable"`；全自动（`?auto=1`）因四家皆 AI，不应有可点击手牌。

### 门户页（推荐入口）

打开 `http://127.0.0.1:7777/` 即门户，可：
- 一键开游戏：一局(1) / 东风场(4) / 南风场(8) / 全庄(16) → `index.html?mode=N`；测试模式 → `index.html?mode=<轮数>&test=1`。
- 设置：长考时间、可选役、显示马牌、显示调试面板、显示牌山 → 保存到 `settings.json`。
- 查看 / 重置大七星与对局统计。
- 打开 `debug.html` 与文档链接。

`index.html` 启动参数：`?mode=N`（目标局数，默认 4）、`&test=1`（测试标记）、`?auto=1&mode=N`（全自动演示）、`?scoretest=1`（计分自测）、`?nostart=1`（只装配+渲染，不开局、不读写 `state.json`；断言页挂载游戏时用）。

## 三、牌山 / 跳墩模型

- 骰子和 S → 定切牌侧；从该侧右端向左数 S 墩（`skipTiles = 2S` 张）= **跳墩**，整局不参与普通摸牌。
- 跳墩 = **4 张岭上（马）** + **王堆（2S − 4）**；马供开杠补摸与赐马，王堆为死牌。
- **活牌山 = 136 − 2S**；配牌后显示的「牌山」= `136 − 2S − 53`，**随骰子变化**。
- 例（配牌后）：S=2 → 79；S=7 → 69；S=12 → 59。
- `cutInfo = {side, stack, skipTiles, maCount, wangCount}`；配位提示行同步显示跳墩构成。

## 五、服务端 API

| API | 方法 | 说明 |
|---|---|---|
| `/api/settings` | GET/POST | 读取/写入 `settings.json`（读取时与默认值合并） |
| `/api/state` | GET/POST | 读取/写入 `state.json`（会话存档 + 运行时命令 `game_cmd`）；POST 回写 JSON |
| `/api/stats` | GET/POST | 读取/累加/重置 `stats.json`；POST 可带 `{wins,rounds,tiisuin,player}` 或 `{kind:'reset'}` |
| `/api/log` | POST | 追加 `logs/output.txt` |
| `/api/roundlog` | POST | 每局每玩家牌型日志 `logs/<会话>/局NNN_玩家_UUID/log.txt` |
| `/api/round_end` | POST | 归档某会话目录为 tar.gz |
| `/api/chrlog` | POST | 浏览器 console 日志 |

**运行时命令（debug.html ↔ 游戏页）**：`debug.html` POST `state.json {game_cmd:{action,...}}`；游戏页每秒轮询 `/api/state`，发现 `game_cmd` 即执行并回写 `null`（不落盘为设置）。
可用 action：`next`（下一局；终局后 = 重开新比赛）/ `auto` / `reset` / `flow` / `setHand` / `speed` / `optional` / `record` / `render`。

> `setScore`（内分）已于 260822 随 `internalScore` 一并移除，不再是可用 action。

## 六、可调用的内部 API

游戏页 `window.__game`：

| API | 签名 | 说明 |
|---|---|---|
| `__game.checker.checkWin` | `(hand, selfDraw, hasCalled, ankanCount, minkanCount, melds, kans, firstTurn, discards, winTile, winCtx)` | 判役。`hand` = **暗手**（牌对象数组）；返回 `{success, totalFu, activeYaku[], reason, sevenHonors?}` |
| `__game.calcPoints` | `(fu)` | 赋 → 子家点数（`0–6: 700fu`；7→7000；28→35000 封顶） |
| `__game.splitPayment` | `(total)` | 自摸三家分摊 → `{each, remainder}` |
| `__game.resolveMa` | `(winner, result)` | 赐马计赋 → `{fu, detail}` |
| `__game.maNextId` | `(id)` | 赐马指示的"下一张" |
| `__game.buildWinCtx` | `(player, winTile, selfDraw)` | 构造 `winCtx` |
| `parseTileString` | `(str)` | `"123m456p789s1122z"` → 牌对象数组 |
| `getAIDiscardIndex` | `(hand, game)` | 弃牌索引（来自 `src/aiPlayer.js`） |
| `conditionFn` | `(id)` | `__game.checker.conditionFn('missing_seven')` 取单役判定函数 |

`winCtx` 字段：`{seaMoon, haiDei, riverFish, lastTileVisible, rinshanFlower, rinshanGun, kanRiichi, renhe, waterDrop, seatWind, roundWind}`。

**牌对象格式**：`{ suit:'m'|'p'|'s'|'z', num: 1..9 | '1'..'7', id:'m1'|'z5' }`
（字牌 `num` 为字符串：1东 2南 3西 4北 5白 6发 7中）

**手牌字符串**：`数字+花色` 一组，如 `11223344556677z`。花色 `m`万 `p`饼 `s`索 `z`字。传 `checkWin` 的暗手张数须匹配（无副露 14 张、每 1 组副露少 3 张、每个杠多 1 张），否则返回 `not_formed`。

   依次跑 yaku 断言（70 用例 / 171 断言）→ engine 断言（18 用例 / 73 断言）→ N 局全自动；输出 `ALL CHECKS PASSED` / `SOME CHECKS FAILED`，退出码 0/1。
   也可 `cmd /c P:\Playground\scripts\run_all.cmd`。**不要**用嵌套 PowerShell 串联（网络盘 + AMSI 会崩）。
